# FoodShop

**URL:** [https://foodshop-vue.vercel.app/](https://foodshop-vue.vercel.app/)

## Description
Sistema de gestión de pedidos para restaurantes y negocios. App Android tipo Glovo, panel para cocineros, impresión de tickets y control de órdenes en tiempo real.

## Tech Stack
- Vue.js
- Android
- Node.js
- REST API
